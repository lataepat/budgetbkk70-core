# Maintenance

Primary maintainer: **Thanapat Thiankrachang (Lataepat)**.

The initial release extracts code developed for BudgetBKK70 with AI assistance. That source project has an existing deployment and revision history. This standalone repository starts its own public history; source-project versions are not represented as public GitHub releases or community adoption.

Proposed release process:

1. Reproduce the reported issue with a focused fixture.
2. Review changes to numeric meaning, district scope, and text preservation.
3. Run tests and the release file check.
4. Document externally visible changes in CHANGELOG.md.
5. Tag the reviewed commit and publish release notes.

The first planned improvements are external-use feedback, additional malformed-input tests, and clearer adapters for other public-budget schemas. No future adoption, integrations, or release dates are promised.
