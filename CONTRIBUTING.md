# Contributing

Use Node.js 22 or newer. Run `npm test`, `npm run example`, and `npm run check:release` before proposing a change. The test suite runs offline without installing dependencies.

For a bug report, include the function, a minimal input, expected output, actual output, and the Node/browser version. Use synthetic records unless the data is genuinely public. Do not include personal casework, account identifiers, API keys, or private source documents.

For changes to record identity or budget attribution, explain the accounting meaning and add a regression test showing that a duplicate, shared project, or missing value cannot silently alter the result. For Thai text changes, include the exact Unicode strings; visual similarity is not enough.

Do not fabricate usage, testimonials, contribution history, or benchmarks. Report performance measurements with the command, sample, environment, and limitations.

Contributions are reviewed by the maintainer. There is no guaranteed response time. Submitting code indicates that you are entitled to contribute it under this repository's MIT License.
