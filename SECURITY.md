# Reporting security concerns

Please report vulnerabilities privately to **t.thiankrachang@outlook.com**, using the subject `BudgetBKK70 Core security report`. This is the maintainer's published professional contact.

Include a minimal reproduction and the affected version. Do not post credentials, personal records, or private data in a public issue. Do not test a live system without authorization. There is no paid bounty or guaranteed response time.

The package processes data supplied by its caller. Applications should impose payload size and nesting limits, validate domain schemas, and restrict untrusted fetch destinations. No external audit or security certification has been performed.
